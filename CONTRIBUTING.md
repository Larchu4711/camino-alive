# Mitwirkung

1. Aktuellen Git-Status und Remote prüfen. Änderungen anderer Beteiligter erhalten.
2. Für Entwicklungsarbeit einen Branch mit dem Präfix `codex/` anlegen.
3. Änderungen fachlich nachvollziehbar halten und betroffene Dokumentation aktualisieren.
4. Zur Änderung passende Prüfungen ausführen und Ergebnisse im Pull Request festhalten.
5. Commits mit einer kurzen Beschreibung der konkreten Änderung versehen.
6. Änderungen über Pull Requests zur Prüfung bereitstellen, sofern der Nutzer keinen anderen Ablauf vorgibt.

Aktuell gibt es keinen Code und damit keine Build-, Installations- oder Testbefehle. Diese werden mit der ersten Implementierung ergänzt.
